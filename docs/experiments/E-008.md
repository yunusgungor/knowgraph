- **Theory:** E-007 APPROVED at 1.00, but post-gate review found the bench vacuous: it mocked retriever.read_node_json only, while enrich_with_conversations imports read_node_json from filesystem inside its own body — so enrich silently resolved nothing, the conversation tail never existed, and edge-order jitter had nothing to flip. The fixed bench (both loaders mocked) scores 0.53 with real tail flips (trials 25/26/31-35). Revised theory: the failure has two layers — (a) enrich appends the SAME conversation node once per matching edge (read_node_json mocked per edge → duplicates C0/C1: result shows ['C1','C0','C1'] — tail has 3 entries for 2 conversations); (b) discovery order follows raw edge-list order, so the tail flips with storage order.
