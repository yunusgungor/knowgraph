## Experiment: E-001 — Hermetic settings construction for deterministic config defaults
- **Date:** 12.09.2026
- **Status:** completed
- **Theory:** KnowGraph's pydantic-settings BaseSettings subclasses implicitly load the repo-root `.env` file (`KNOWGRAPH_QUERY_TIMEOUT_SECONDS=30.0`) and ambient `KNOWGRAPH_*` environment variables. Unit tests asserting canonical defaults (e.g. `timeout_seconds == 60.0`) therefore depend on cwd and environment: `QuerySettings().timeout_seconds` is 30.0 when run from the repo root but 60.0 from /tmp. This ambient-config leakage makes the suite inconsistent across machines/CI (observed: 61 passed, 1 failed in tests/test_config.py from repo root). Test-hermeticity principle: unit tests must not read ambient config; stripping `KNOWGRAPH_*` vars and ignoring `.env` (`_env_file=os.devnull`) should restore canonical defaults deterministically.
