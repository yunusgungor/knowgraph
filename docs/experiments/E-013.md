## Experiment: E-013 — Stop-hook phantom targets from read-only probe commands
- **Date:** 09.09.2026
- **Status:** completed
- **Theory:** After tightening code_guard/stop_guard to hard, Stop denied on "Unapproved code changes detected: *.py". Audit-trail analysis proved no *.py file was written (git tree clean): the touched set came from extract_bash_targets parsing read-only terminal commands. Two phantom classes: (a) glob strings ('*.py' from grep --include flags quoted inside python -c bodies) accepted as write targets; (b) dotted module paths ('knowgraph...retriever.SparseEmbedder' from -c import lines) accepted as file paths. Proposed fix (validated in-memory): in the -c branch, skip quoted hits containing glob chars ([*?[]) and slash-less dotted identifiers ([A-Za-z_]\w*(\.[A-Za-z_]\w*)+). Real write paths (out.txt via open(w), scripts/gen.py via run()) still detected — one gap found during validation: out.txt is caught by the open(w) regex, not the quoted-string branch, so the filter must not suppress the open/write/copy regexes.
- **Hypothesis:** H-013: "filter_accuracy >= 0.90"
- **Measurement Metrics:** filter_accuracy >= 0.90 (fraction of 40 labeled commands where the patched extractor returns exactly the expected write-target set: empty for read-only probes with globs/imports, exact paths for real open(w)/write_text/copy/redirect writes)
- **Experiment Design:** Bench feeds 40 fixed labeled commands (20 read-only probes that must yield no unapproved target + 20 real-write commands incl. open(w)/write_text/copy/tee/redirect shapes) through the patched function and scores exact-set equality per command. The patch lives OUTSIDE the repo (plugin cache) so the bench vendor-copies the function source read-only (patched package dir in temp, no repo write of the artifact) — the measured artifact is the patch text. Falsifiability (two independent legs): (a) session replay — 9/129 session terminal commands yield glob/dotted phantoms through the UNPATCHED extractor (incl. the exact commands that wedged Stop); the patched extractor must yield zero on all 9; (b) the 40-case matrix — unpatched code fails the glob-phantom cases there; a filter that also suppresses real writes fails the write cases.
